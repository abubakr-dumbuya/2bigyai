# Joloff Restaurant Website

Five-page website for Joloff Restaurant — Brooklyn's home for authentic Senegalese cuisine since 1995.

## Pages
- `/` — Home
- `/menu` — Restaurant Menu
- `/story` — Our Story
- `/events` — Events
- `/catering` — Catering & Inquiry

## Deployment
Deploy with Vercel CLI:
```
vercel --prod
```

The `vercel.json` file maps clean URLs to the HTML files.
